# Habitat Papers

When the user asks about the habitat/radiomics papers they previously listed, local journal PDFs/supplements, Wang-style MRI habitat methodology, osteosarcoma habitat references, or how papers handled resampling, K selection, silhouette coefficient, or voxel/feature-map clustering, read `references/papers.md` first.

Use the Windows root `D:\projects\Habitats\papers`; in this environment it usually maps to `/host/d/projects/Habitats/papers`.

Do not assume exact filenames beyond the listed titles. If a precise PDF/DOCX path is needed, search under the papers directory using title fragments.
